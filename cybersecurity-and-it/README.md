# Cyber Security & IT

The Cyber Security & IT branch of the Upper Circle Academy. Each course is a
subfolder with its own toolbox, labs and field resources, mirroring the branch
on the site.

## Courses

- **`pentesting/`** — Penetration Testing (CY-01). A containerised attacker
  toolbox (built and published to GHCR by CI), plus lab guides and Windows/AD
  cheat-sheets that bridge the in-browser course to a real, self-hosted range.

Planned: additional Cyber Security & IT courses as they come online.
