# Upper Circle Academy

Companion infrastructure for the UC Academy Accelerated Programs (UCAP) — the
hands-on labs, toolboxes and field guides that pair with the courses on Upper
Circle (<https://connectedummah.lovable.app/academy>).

The repository mirrors the Academy's structure on the site: each **branch**
(field of study) is a top-level folder, and each **course** within it is a
subfolder carrying its own toolbox, labs and resources.

## Branches

| Branch | Folder | Courses |
| --- | --- | --- |
| Cyber Security & IT | `cybersecurity-and-it/` | Penetration Testing — `cybersecurity-and-it/pentesting/` |

Further branches and courses are added as sibling folders as they come online.

## Authorised, educational use only

Everything here is for learning against systems you own or are explicitly
authorised to test — your own isolated lab VMs and the deliberately vulnerable
ranges named in the guides. Keep vulnerable labs isolated from real networks
and the internet.
